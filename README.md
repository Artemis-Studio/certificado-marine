# Emissor de certificados — Marine Telematics

Página estática que gera o certificado de conclusão do treinamento técnico em PDF, direto no navegador.

**Uso:** abra a página, preencha os campos do painel à direita e clique em **Salvar PDF** → destino "Salvar como PDF", layout **paisagem**, margens **nenhuma**, com **Gráficos de plano de fundo** marcado.

Os dados digitados ficam salvos no navegador de quem emite (nada é enviado a servidor nenhum — a página não tem back-end). O botão **Padrão** limpa tudo.

O layout é A4 paisagem (297×210 mm) e está travado: só o texto muda.
